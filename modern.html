Decent UCAN Play — Modern Path

The original app remains available at the legacy entry. This modern path is a static browser app with bring-your-own Pinata keys, local DID generation, and client-side UCAN session delegation.

1. Bring your own keys

2. Create or resume a local DID

3. Upload to Pinata from this browser

4. Recent uploads for this DID

    How the modern path works

    • Your Pinata credentials stay in your browser storage only.
    • Your root DID and delegated session DID are generated locally with @ucanto.
    • The UCAN delegation is used as the app's local capability session envelope.
    • Uploads and listing calls go directly from the browser to Pinata using your BYOK settings.
    • If you later want a more decentralized remote-storage path, Helia + Kubo/IPFS Cluster is the next step, but it adds operational overhead compared with Pinata BYOK.
