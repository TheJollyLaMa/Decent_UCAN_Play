Decent UCAN Play — Modern Path

The original app remains available at the legacy entry. This modern path is a static browser app with bring-your-own Pinata keys, local DID generation, and client-side UCAN session delegation.

1. Bring your own keys

By default the JWT stays in page memory, not persistent storage. Never paste an organization or shared project credential here. Pinata receives this JWT directly; the local UCAN does not restrict its provider permissions.

3. Upload to Pinata from this browser

Files are not encrypted here. Pinata receives filenames, content, owner/session DIDs and the delegation CID. DID filtering is discovery, not access control; a CID is not a secret. Unpinning is not guaranteed deletion from IPFS.

4. Recent uploads for this DID

    How the modern path works

    • Your JWT is sent directly to Pinata over HTTPS; it remains in page memory unless you explicitly choose unencrypted persistent storage.
    • Your root DID and delegated session DID are generated locally with @ucanto.
    • The UCAN delegation is a local learning/session envelope. Pinata does not verify it or enforce its expiry; revoke the JWT at Pinata to revoke provider access.
    • Uploads and listing calls go directly from the browser to Pinata using your BYOK settings.
    • If you later want a more decentralized remote-storage path, Helia + Kubo/IPFS Cluster is the next step, but it adds operational overhead compared with Pinata BYOK.
